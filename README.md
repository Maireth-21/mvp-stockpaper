# mvp-stockpaper

Aplicación web para la gestión de inventario y control de créditos en la Papelería Yusuqui.

---

## Descripción del Proyecto

StockPaper es un software desarrollado con el propósito de optimizar los procesos administrativos de pequeñas papelerías, permitiendo llevar un control organizado del inventario, clientes, ventas y créditos.

El proyecto surge a partir de la necesidad identificada en la Papelería Yusuqui, donde gran parte de la información se maneja manualmente, generando errores en el registro de productos, dificultades en el control de deudas y poca organización administrativa.

El objetivo principal del sistema es digitalizar estos procesos mediante una plataforma web moderna, sencilla e intuitiva.

---

## Arquitectura del Sistema

El sistema utiliza una arquitectura basada en el patrón MTV (Modelo - Vista - Plantilla), relacionado conceptualmente con MVC.

### Componentes:
- Modelo: gestión de datos y conexión con la base de datos
- Vista: procesamiento de lógica y solicitudes
- Plantilla: interfaz visual para el usuario

Esta estructura permite mantener una separación organizada entre la lógica del sistema y la interfaz gráfica.
